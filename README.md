# Navigating through complexity: a roadmap to disentangle multi-level drivers of intraspecific seed trait variability and prioritise research efforts

Roberta L. C. Dayrell, Efisio Mattana, Pablo Gómez Barreiro, Richard Buggs, Michael D. Charters, Udayangani Liu, Michael Renton, Phoebe Swift, Ted Chapman and Charlotte E. Seal.

*New Phytologist*, 2026.

## Scripts

| Script | Purpose |
| --- | --- |
| `01_seed_quality.R` | Maps sampled populations, fits bioclimatic models, partitions variance in embryoless seed fractions, and produces Figure S1 and three plot objects for Figure 2. |
| `02_seed_morphology.R` | Partitions variance in seven seed morphology traits among populations, among trees and within trees; produces the fourth plot object for Figure 2. Includes reference code for trait correlations and transformation diagnostics. |
| `03_assemble_figure_2.R` | Combines the four saved plot objects into Figure 2. Run scripts 01 and 02 first. |
| `04_theoretical_maternal_variation.R` | Produces the conceptual illustration in Figure 3; requires no input data. |
| `05_crataegus_germination.R` | Fits germination models for successive stratification rounds, calculates contrasts and confidence intervals, and produces Figures 4 and S2. |
| `06_alnus_genetic_seed_quality.R` | Tests correlations between Alnus population genetic indices and embryoless seed fractions, producing Figures 5 and S3. |

## Input files

The original datasets generated by this work are publicly available on Figshare. To reproduce the analyses, download the data through the link below and save the files in `data/` before running the scripts.

Dayrell RLC, Mattana E, Gómez Barreiro P, Buggs R, Charters MD, Liu U, Renton M, Swift P, Chapman T, Seal CE. 2026. Data from: Navigating through complexity: a roadmap to disentangle multi-level drivers of intraspecific seed trait variability and prioritise research efforts. Figshare [dataset]. doi: [10.6084/m9.figshare.34584591](https://doi.org/10.6084/m9.figshare.34584591).

- `embryoless_seeds.csv`
- `morphology_tpif.csv`
- `crataegus_germination.csv`
- `genetics_alnus.csv`

The bioclimatic variable names (`data/bioclim_names.csv`) are included in this GitHub repository. Script `01_seed_quality.R` downloads the GADM map boundaries automatically if needed.
